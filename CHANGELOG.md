# Changelog

## 1.0.0

First public release.

- Ten content types: link, text, Wi-Fi, contact (vCard), email, SMS, phone call, WhatsApp, location, calendar event
- Fields are checked as you type, with clear messages in Arabic and English
- Live preview, and an automatic scan check on every code
- Six quick styles, gradients, seven dot shapes, four corner shapes, logo, caption and frame
- Export to PNG, JPG, SVG (vector), PDF, WEBP and BMP, or copy to the clipboard
- Many codes at once from a list or a .txt / .csv file
- Read QR codes from an image or the clipboard
- History with search
- Arabic and English interface that follows the system language, light and dark themes
- Standalone Windows .exe and macOS .app / .dmg
